## Selected Projects

### [Quant Data Pipeline & Portfolio Optimization](https://github.com/RealHarounJ/quant-data-pipeline)
Automated market data ingestion into PostgreSQL with zero-duplicate upserts, Markowitz Mean-Variance portfolio optimization for Maximum Sharpe Ratio, and 10,000-path Monte Carlo simulations for Value-at-Risk forecasting. Containerized with Docker Compose and scheduled via Apache Airflow DAGs.
- `Python` `PostgreSQL` `Apache Airflow` `Docker Compose` `SciPy`

### [Clinical Analytics & Health Economics in R](https://github.com/RealHarounJ/philips-healthtech-clinical-analytics-r)
Predictive clinical deterioration models (AUC = 0.902) using Kaplan-Meier survival analysis and Decision Curve Analysis (DCA). Includes digital signal processing on 100 Hz PPG biosignals and a 1,000-iteration Markov decision model demonstrating cost savings in intensive care environments.
- `R (Tidyverse, survival)` `Biostatistics` `DSP` `HEOR`

### [AFML Quantitative Trading Engine](https://github.com/RealHarounJ/afml-prop-trader)
Algorithmic trading framework based on Marcos López de Prado's *Advances in Financial Machine Learning*. Implements fractional differentiation for stationary time-series with maximum memory retention, Lempel-Ziv entropy regime detection, and triple-barrier risk controls.
- `Python` `MetaTrader 5` `NumPy` `SciPy`

### [Financial Relational Database Architecture](https://github.com/RealHarounJ/financial-db-design)
Normalized enterprise schemas for transactional records, billing systems, and accounting data. Tuned for query execution efficiency using window functions, common table expressions, and targeted indexing strategies.
- `SQL` `PostgreSQL` `Database Modeling` `Query Optimization`
